# Rayquaza lane guide: truck to the third badge

Draft for the operator's review, 2026-11-05. Route: keepingiticy's speedrun order, so Stone, Dynamo, Heat, with Dewford's gym left alone. Starter: Mudkip. No RNG manipulation.

Each row is one note the harness sends, as a short final message, when the milestone in the first column is earned. It repeats on entering the map named in the note and on a stall there. `CHECK` marks a line not yet confirmed against recorded game state.

Sources: **KI** keepingiticy findings (`keepingiticy-video/findings.md`); **WT** private notes walkthrough, by part; **GR** gold run scripted through the game, seg1 and seg2; **TR** recorded traces; **PATH** `runs/keepingiticy-video/paths/`; **The operator** operator note.
