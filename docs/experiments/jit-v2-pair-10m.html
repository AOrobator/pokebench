JIT v2 · one-pair pilot

One JIT run and one control run. Ten minutes each. Diagnostic only; no promotion or automatic expansion.

Mechanism

V1 diagnostics found 533 unknown-interface fallback requests of 1,640 and increased uncached input. V2 keeps a stable core, full tools and temporary known-interface guides. Unknown interfaces add no guide. Benefit remains unmeasured.

Start

Both arms load the same recorded fast-text MAIN_MENU state before the first changed prompt. The isolated current-build load visibly shows NEW GAME selected. This is conditional checkpoint evidence, not a fresh boot record.

Arms

Only just-in-time-prompt-v2 differs. The newer truthful-checkpoint-task flag is explicitly OFF in both arms to preserve the proposed control. Same model, source, tools, sampling and starting save. V1 OFF in both.

Outcomes

Primary descriptive ordering: furthest native story checkpoint, then arrival time. Legacy RIVAL_MET field is not a target stop. Secondaries: uncached input, cache reuse, TTFT, inference/request, output/request, prompt composition and retained guide volume. Separate first request from later requests.

Power

One run per arm: two-sided Fisher power is 0%, even for 0/1 versus 1/1 (p=1). This pilot inspects operation and mechanism; it cannot establish improvement. No powered effect estimate or winner claim.

Order and failures

One GPU, sequential JIT then control, fixed seed 000000000000042c. Each run has a 600,000 ms cap, 20,000-turn ceiling and no milestone target stop. Model errors and crashes remain outcomes. Zero replacements. Total 20 GPU-minutes plus startup. No cache clearing or server restart. No contact with occupied lanes; existing runs finish naturally.

Limits

Run order, inherited server cache and stochastic behavior confound comparison. Repeated requests are not independent trial replicates. No promotion, significance or broader gameplay claim. Existing known task-only startup anchoring remains; unknown startup creates no guide.
