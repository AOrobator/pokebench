# JIT v2 cache-fix pair: farther frontier, no serving-speed win

**Verdict: INCONCLUSIVE overall; IMPROVE the stale-goal bug before promoting either configuration.** One completed 20-minute run per arm, concurrently on separate GPUs. Both ended at their caps, with no recorded error events and complete usage for every response. JIT reached Oldale and healed; control did neither. JIT also subsequently returned toward the obsolete lab goal.

## Why the cache percentage still favors control

Each run retains an unchanged system-prompt hash and tool-catalog hash. Control has a larger empirical cached-prefix floor (4359 tokens versus 2450). Subtracting each empirical floor once per request yields an illustrative residual reuse share of 61.42% control versus 61.69% JIT. This is not a directly measured history-only metric: it shows that the headline ranking depends strongly on fixed-prefix size.

All post-start cache-floor resets coincide with detected context pruning: 79/243 subsequent control requests and 69/211 JIT requests (about 32.5% each). There are zero resets outside those detected pruning requests. The five JIT guide additions without detected pruning have 86.4% aggregate cache share and 427 ms median TTFT. Retained ordinary-append requests have almost identical mean TTFT: 513.7 ms control and 512.0 ms JIT.

Pruning requests account for 74.2% of JIT uncached tokens and 72.0% of control uncached tokens. JIT pruning requests average approximately 2.38 seconds TTFT versus 2.23 seconds control. Therefore guide reuse and coalesced cuts eliminated the prior independently timed history-cut pattern, but image/result rewriting still destroys most suffix reuse about every third request. These classes use message/image count drops; exact server token-prefix traces were not recorded.

The earlier 10-minute diagnostic pair had different source, budgets, staggered starts and trajectories. Its fixed-floor-subtracted diagnostic shares were 57.0% JIT /55.1% control, versus 61.69%/61.42% here. This is consistent with improved reuse but is not a causal estimate of either new cache flag. The shared window flag is ON in both current arms; this pair does not independently test its benefit against legacy window behavior.

## Both trajectories expose the stale-goal harness bug

Control turn 205, seq 4605: the model interprets a five-minute stall briefing as a reason to head south, despite the briefing and readout identifying north toward Oldale. Its authoritative Story goal still points to Birch’s already-fulfilled lab invitation. Earlier it repeatedly misidentifies a generic Route 101 youngster as MAY. Recorded frames and RAM were checked in the separate control-turnaround report.

JIT turn 202, seq 5170: immediately after healing it states, “The story goal is still to go to PROF. BIRCH’S POKéMON LAB”. Turn 204, seq 5219 selects the southern Oldale exit; turn 210, seq 5401 is back in Littleroot pursuing the lab. Thus JIT’s higher achieved frontier is real, but it also follows the same stale goal. The harness bug affects model-visible goal priority in both arms; it does not invalidate recorded token/latency measurements or earned Oldale progress.

## Interpretation and recommendation

The cache-specific mechanism looks healthier: the stable JIT core/catalog and guide-only additions do not cause extra observed floor resets. The remaining dominant cost is rewriting early image/result history. JIT does not win end-to-end request latency in this pair and does not show robustly better gameplay; one trajectory per arm cannot separate treatment from GPU or gameplay variance. The hundreds of request measurements diagnose these two trajectories, but are correlated observations rather than hundreds of independent experimental runs. Neither reached the Route 103 rival battle.

Recommend IMPROVE: repair stale-goal bookkeeping independently, preserve the minimal JIT design, and treat image/result prefix stability as the next cache issue. Retain the incumbent; no preset promotion, code change, new launch or GPU action was performed. Any follow-up comparison needs fresh authorization and a frozen protocol; counterbalance arms across GPUs. This operator-authorized one-pair pilot is below the skill’s eight-per-arm screen.
