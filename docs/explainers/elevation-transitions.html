navigate_to now climbs stairs and crosses bridges

Every map tile has an elevation from 0 to 15, and the player carries one too. The game refuses a step onto a tile at a different height. planNavigation had two rules wrong: it kept the old height on stairs, and it took on height 15 on bridges. It now copies the game's two rules exactly. This is a fix inside bounded-navigation-v1; there is no new switch.
