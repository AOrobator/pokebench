The experiment queue: every switch gets measured, in order, only when it can matter

Each merged feature switch becomes an experiment: the incumbent configuration against the same configuration with that one switch flipped, 8 trials each. The queue runs them one at a time under the same gameplay lock NEXT RUN uses. It waits for your approval, and it never queues an experiment the models can't reach yet.

2. The readiness gate: only test where models arrive

Your rule: don't run an experiment until the models reliably reach the part of the game the switch changes. Each experiment names its activation milestone. It is ready when at least 3 of the last 4 qualifying runs on its model lane reach that milestone.

PokéNav has an EXPERIMENT QUEUE page, and Runs & Comparisons has EXPERIMENT QUEUE and PENDING EXPERIMENTS sections. Each experiment is a party slot: its trial pips in run order, an HP bar per arm for how many trials reached the rival house, and median turns.
