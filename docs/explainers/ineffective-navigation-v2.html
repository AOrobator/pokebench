The detector groups free-field attempts that leave the position and relevant game conditions unchanged. Three attempts trigger the existing ineffective-loop event. Turning or moving fewer than four tiles from the episode origin does not discharge it. Four tiles of displacement, a changed condition or qualified interaction can recover. Native story progress resets it.

Boundaries

No count is added for errors, battle, menus, locked/unknown fields or successful partial walks. It never presses a button or chooses a route. Geometry comparisons use overlap in the bounded local tile window. Nearby objects and triggers are compared by identity, so scrolling the window alone is not recovery. Missing optional evidence never proves a change; known condition changes still can.
