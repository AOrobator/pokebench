When a guide is added

At the actual request dispatch: first request, verified scene change, or loss of the active guide’s observation during context trimming. Repeated requests retain exact guide text and timestamp. Tool-call IDs anchor guides through observation collapse; intervening canonical assistant replies can anchor a newer guide after those replies. Evicted guides leave the projection; needed current guidance is appended at the newest retained observation. Transient instruction ledgers do not become anchors.

Each guide applies only to its labelled interface. Current screenshots and readouts determine input ownership. Unknown scenes receive the existing full fallback instructions at the tail. Cross-scene trust, evidence and supervisor rules remain in the core. V2 adds no execution guard or tool filter.

Recorded evidence

Assistant request_context.mode = jit-v2 records the exact core and hash, full tool names and definition hash, current scene/state sequence, active guide’s original source state, anchor, ordinal, text/hash and injection reason. projected_guidance lists every retained guide. Activity History and raw inspection preserve these receipts; no timeline marks are added.

component_chars.core_text and guidance_text count raw text characters. canonical_history_json counts serialized canonical history including image encoding; it is not text tokens or directly comparable with the two text counts. Provider token and cache counters remain the source for request size. No invented per-section token estimates.

Limits and OFF behavior

OFF takes the existing full/v1 path unchanged. V2 does not prevent prefix changes caused by baseline history collapse, screenshot pruning, changing ledgers, provider formatting, or backend cache eviction. Tests prove the v2 projection preserves its retained bytes; only a new experiment can measure backend reuse and gameplay progress.

Implementation and tests are on codex/jit-v2-stable-prefix. Review and landing status live in the active worklog. The separate ten-minute screen remains a proposal.
