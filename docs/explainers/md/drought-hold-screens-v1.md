# Drought holds on battle screens

> Markdown twin of [drought-hold-screens-v1.html](../drought-hold-screens-v1.html), generated from the HTML by `just explainer-twins`. The HTML is the source; edit it, not this file.

`drought-hold-screens-v1` keeps the "no new story milestone" note back while an evolution or move screen from a battle is up.

## Why it exists

Run 37ca got the drought note on the evolution screen right after beating Flannery. A battle already holds a due note; the screens a battle hands control to did not.

## On

While the game is still in a battle and an evolution or move-forget screen owns it, a due note is held, then dropped when the screen closes, and the count starts again, as for a battle.

## Off

The note can be sent on those screens.
