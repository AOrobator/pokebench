Named warp destinations

The readout lists every door and staircase on the map. Today it says only where each one leads by number, such as map 1/2. With this switch on, it also gives the place's name from the game's own map table, such as LITTLEROOT TOWN MAYS HOUSE 1F (map 1/2). That is the same name the Location line shows after walking through.

Why it exists

Mom tells the player that Prof. Birch "lives right next door". In the Think Fast 2×2 (trials 01–09), every run repeats that line correctly, then turns it into "go to Birch's lab". Outside, nothing in the readout says which building a door belongs to, so the model guesses what map 1/2 is.

The "Warp to …" label appears when named interactions are on (as in the 2×2). With them off, only the destination at the end of that line is named. Only these three lines change; the JSON state used for grading is identical.

Where the names come from

The game stores each map as a group and number. The name is looked up in the game's own map list (data/maps/map_groups.json in pret/pokeemerald, vendored with PokeAgent), using the same lookup that writes the Location line. No name is written by hand.

Wiring

How it differs from map destinations

world-destinations-v1 already prints the same names, but as separate lines at the very end of the readout (Warp destination at (14,8): LITTLEROOT TOWN MAYS HOUSE 1F), together with map bounds and connections. This switch puts the name inside the lines the model reads when it picks a door, and changes nothing else. Both can be on at once; the name then appears twice. The operator asked for this one to be tested first.
