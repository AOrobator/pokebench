Break a navigation loop without choosing the destination.

navigation-recovery-v1 adds qualified current-map feedback and keeps map-cycle recovery active. Every navigation action remains available, including returning the way you came.

Two failures, one switch

The recovery budget starts after feedback delivery. Battle and owned-menu calls pause it. Unknown observations do not establish recovery. This guard never presses a button or silently changes a request.

What counts as recovery?

Stale map: navigation addressed to the qualified current map actually sends input and returns a qualified field observation. This establishes corrected map addressing, not story progress.

Map cycle: a qualified observation confirms a map not visited since the last native story progress, or a new native story milestone occurs. Previously visited detours, rotation and fresh event numbers do not retire the episode.

Observed walking exits are listed with exact request arguments, with unvisited destinations first. Unsupported and water-only exits are excluded. A selected target alone never proves arrival.

OFF preserves the previous feedback and stopping. ON warns after two qualified stale-map refusals, or persists an existing map-cycle warning. The tests replay preserved events through the production guard factory and verify feedback through the pinned model loop.

Backtracking and scope

A normal out-and-back trip does not activate this guard. During a warned cycle, backtracking still executes; a long trip through known maps can exhaust the twelve eligible field-call budget. Battles and owned menus pause that budget. Story progress retires it so return journeys can continue.

No destination, character location, route order or objective is hardcoded. This uses existing qualified map identity, position, exit reach and native milestone records; it adds no RAM decoder or game-state inference.

Status: implementation candidate; recorded replay is a correctness check. Review, landing and measured gameplay benefit are separate gates. Experiment remains pending and unapproved.
