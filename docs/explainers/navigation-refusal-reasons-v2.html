Harness switch · navigation-refusal-reasons-v2 · default OFF · bundle arm only

Say when the route leaves the local map

Local navigate_to plans over the 15x15 tiles around the player. When the target is inside that window and walkable but no route reaches it inside the window, today's refusal gives no reason. With this switch on, it says the route leaves the local map and names the reachable tiles on the window's edge, one per side, nearest the target first.

Before and after

OFF

no supported local path; choose a reachable local waypoint

ON

no route to (6,4) lies inside the 15x15 local map navigate_to plans over, so any route leaves it; reachable tiles on its edge, nearest (6,4) first: (6,16) on the south edge, (14,9) on the east edge; walk to one, then call navigate_to (6,4) again

If no edge tile can be reached: "…, and navigate_to can reach no tile on that local map's edge from here; choose another target".

Rule

StepCondition
AppliesLocal mode; the planner found no path; no earlier reason (counter, refusal-reasons-v1 target reason, navigation-truth trigger reason) applies; no route reaches the target inside the window even with ledge hops, one-way tiles, walkable floor and the game's elevation rule counted and matching coordinate triggers ignored, so a route the run's own terrain switches miss (ledge-hops-v1, one-way-tiles-v1, walkable-floor-v1 or elevation-transitions-v1 off) keeps the generic text; the target tile is in the window and the player could stand on it (walkable, no person, object or warp on it); the map size is known (topology). A wall, water, person or warp target keeps the generic text even with refusal-reasons-v1 off.
Edge tileA window tile with a 4-neighbour inside the map but outside the window; standable, no object or warp on it; the planner reaches it. Matching coordinate triggers are excluded (as stand tiles and on the way) only when navigation-truth-v1 and coordinate-script-conditions-v1 are also on; with v2 alone the planner's ordinary rules apply.
ListedPer side (north, south, east, west) the edge tile nearest the target (Manhattan, then row, then column); sides sorted by that distance.
NeverTurns on whole-map navigation (full-map-navigation-v1), walks anywhere, or guesses tiles outside the window.

The listing is not a route: the nearest edge tile can still be the wrong side (show T800 lists south before east). It names every side so the model can choose.
