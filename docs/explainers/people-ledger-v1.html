People ledger

Right under the readout's Location and Position lines, the model sees every object the game has loaded on the current map, by its map-local object id, sprite kind and position, and when it last talked to that object: the turn, how many turns ago, and how many story milestones the game has confirmed since. Story characters are named where character presence places them. Facts only, nothing clipped.

How "last talked to" is counted

RuleWhat the code does
Who was talked toThe object the player faces in the state recorded with the conversation's first page: the next tile in the facing direction, or, when that tile is empty and is a counter (MB_COUNTER 0x80), the tile beyond it. Only an object at the player's elevation counts, unless the player's tile or the object has elevation 0 (ELEVATION_TRANSITION), as in GetObjectEventIdByPosition; so on a bridge the ledger picks the bridge object, not the one underneath. This is how pokeemerald 731ad5bf GetInteractedObjectEventScript (src/field_control_avatar.c) picks whom A talks to. The player's elevation is the current one the server reads; the game uses the previous one, which only differs mid-step.
What counts as a talkA dialogue_auto_advance event with a faced object, where the model's press ended in A, or the page record already attributes the first page to that faced sprite (speaker_source: faced_sprite, e.g. a scripted person who walks up and speaks without a name prefix). Story characters in cutscenes often have no script of their own and are not listed at all: May walking up at turn 161, Mom upstairs at turn 68 and Birch on Route 101 at turn 252 count for no one. A navigate_to that ends in a message from someone the player does not face counts for no one. Battle text pages (battle-text-auto-advance-v1) are skipped: the first field page of the call decides, and a call with only battle pages counts for no one. A readout taken in battle gets no block.
When it countsOnce its tool result reaches the model; an error result drops it. The call that shows the conversation already lists it as "this turn".
Who is listedThe map's object targets in the typed state (interaction_targets of kind object): every one of the game's 16 object event slots that is active, visible, on this map and has a script, with live position and current elevation (world.py read_targets). That is not limited to 7 tiles like the Field objects list: at state 889 in Littleroot it lists object 3 (BOY_2, at 14,17) while the player stands at 4,10. Objects without a script, such as the moving truck, are not listed. The game itself loads only objects near the camera, so a far corner of a big map can still be missing.
IdentityThe current map id plus the map-local object id. Several people share a sprite kind; the same local id on another map is someone else.
Story charactersOnly from character-presence-v1's own line: a character it places at x,y names the object on that tile (MAY (sprite RIVAL_MAY_NORMAL)), and its here and not-on-this-map lists are repeated under the block. With character presence off, nobody is named and the line is absent.
ScopeStarted overworld readouts only (no battle, menu-only or pre-game screens). All live objects, never clipped. "Not talked to this run" means since this run started, including a checkpoint start.
