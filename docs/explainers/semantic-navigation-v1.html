Semantic navigation v1

The model chooses a game-owned target. The harness owns the coordinate work: current identity, route, running, approach tile, facing, and one activation.

The red path is not a failure to hide. The result names why travel ended and includes the verified state that now owns input.

People
Resolved by current map-local object ID, so a sprite name or old coordinate is not treated as identity.
Fixed interactions
Resolved by listed kind and map coordinate; elevation and reachable approach remain planner checks.
Exits
Warps use their listed tile. Walking connections use the current map's verified edge tiles and direction.
Interruption boundary
The harness never answers dialogue or chooses a battle action. It returns control on the first new owner.

Running displacement

A held running press can cross more than one tile. It counts as progress only when every crossed tile is the next collinear prefix of the route planned immediately before the press. Pushback, teleportation, or an off-route landing still stops navigation.

OFF: navigate_to_target is absent. Coordinate navigate_to remains the model's interface.
