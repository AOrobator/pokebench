Unfinished activity memory

unfinished-activity-v1 · guidance · bundle arm only · default off · needs ram-state-v1

The agent's own walk back

Rules

PartComes fromRule
Opensrecorded battle states (BattleOutcomes), trainer from trainer_opponentA trainer battle the agent lost or drew. A later loss to the same trainer updates it. Wild battles never open one.
Closesthe trainer's defeated flag the game setsOnly when a state shows that trainer defeated, or a later win against it. Detours, story milestones, briefings and context trims never close it.
Startedmap arrivals, party HP, activity heal and blackout eventsFrom the arrival before the first trainer battle on that map: came in, beat or lost to a trainer, left with each party member's HP, heals recorded elsewhere, came back.
Still opendelivered field dialogueThe field pages the game showed on that map in the call that started the battle, whole, then the latest reading of the trainer's flag.
Own walkarrivals plus the game's map tableA step is a map-table door within two tiles of where the player last stood, or a map edge. A whiteout or scripted move starts over. Coming back through the exit it left by removes that loop. The walk starts at the latest exit of the current map in it that exit_reach lists as reachable on foot; with none, the whole walk is shown.
Story linestory-destinations' resolverA line whose every place is a map entered since it was said reads "Story line heard … Reached: MAP, first entered at turn N" (the first entry since the line, not the latest visit); a line said while the player is already in the map it names reads "you were in it when this was said (since turn N)". Either way it does not drive the walk-away note. A newer line none of whose places resolves does not replace an older one that does.
Supervisor notesunfinished_activity eventsLoop, stall and text-only notes add "- Unfinished activity (what you did and what the game recorded): " with each open item.

Nothing is clipped. Each opening, update and retirement is one unfinished_activity event in Activity History and the raw-event inspector; there is no timeline mark.
