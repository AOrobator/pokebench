Untaken exits

Rules

PartRule
ExitsEvery warp event on the current map (all of them, not only those in the local map window), grouped by exact destination so a two-tile door is one exit; with world-destinations-v1 on, every map connection too (the readout only shows connections with that switch).
TakenThe same exit history as briefing-exits-v1: on each recorded map change, the warp next to the last tile on the old map and the warp back next to the first tile on the new map (with same-destination siblings); a connection is crossed when the change used no warp. A same-map warp (teleporter pad) counts when the player lands exactly on the warp it leads to. The wrapper also feeds the result's own state to the history before writing the line, since a live result's state is recorded only after the tool returns. Kept for the whole run, never reset.
NamesThe names the run's readouts gave to maps (Location lines, named warp and connection destinations); otherwise map g/n. Dynamic warps read dynamic destination.
PlacementRight after the Position line, else after the Location line, in observe, press and navigate_to results. Nothing is clipped. With every exit used: none (you have taken every exit on this map this run); with none listed: none (no exits are listed on this map).
Not shownOutside a started overworld readout, or without interaction targets (world-targets-v1 off).

Separate from talk-to-people guidance

explorer-guidance-v1 (another branch) is a prompt section about talking to people. This switch is about exits, with its own readout line, so the A/B can tell the two apart. people-ledger-v1 (unmerged) also inserts a block after the Position line; with both on, each wrapper inserts right after Position in turn and neither line is lost.

Wiring

playGameTools (live runs and decision probes) wraps observe, press and navigate_to with withUntakenExits when the switch is on; it subscribes once to the recorder for the exit history. playSystemPrompt appends the sentence. Off: the same tool objects, no subscriber, the same prompt bytes. The switch is refused in state-only mode, which has its own prompt.
