## Hypothesis

Ordinary sliding context drops observed instructions and failed destinations. A bounded persistent ledger of actually delivered dialogue, rooms, attempted interactions and measured outcomes, plus an optional evidence-linked model destination hypothesis, may reduce wandering without supplying a route. The harness must not decide the story goal, infer script answers, mark model claims complete or enforce objective tracking.

## Contract and invariants

- INV1: independent `navigation-evidence-memory-v1` flag; OFF exposes no tool or injected ledger. ON/OFF source, measurement, prompt except declared memory text/tool, serving, sampling and all other flags equal.
- INV2: facts come from recorded observations already eligible for model delivery. Exact event sequence links, room identity and truncation are retained. No script walkthrough, future state, hidden ablated fields or private reasoning extraction.
- INV3: destination is a model hypothesis, never native completion or automatic next milestone. Writes require known observation evidence. Invalid writes are typed, bounded, clearly rejected and recorded.
- INV4: bounded per-run memory, deterministic trimming, retained uncertainties and no game inputs by memory owner. Every emitted context has an exact recorded payload, timeline and activity/replay visibility.
- INV5: eight fresh boot runs only, four per arm, serial order A B B A B A A B (OFF/ON). 30 minutes and1500 turns, no milestone stop, automatic running and objective enforcement OFF. Existing native grading/correctness common ON.
- INV6: no rescue, mid-cohort edit, silent rerun or automatic promotion. All launched failures retained. Verify live viewer8793 and full frozen identities before launch.
