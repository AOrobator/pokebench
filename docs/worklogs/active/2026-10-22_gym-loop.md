# Gym practice loop from the Rustboro save

## Problem
The operator (2026-10-22 3:21 PM): loop gym training with no budget, as much data as possible, picking up main like the whole-map loop, LLM-free and automatic. Codex's gym switches are on main and in the bundle.

## Design
- `experiments/fixed/gym-rustboro-torchic.json`: the reviewed design (runs/reports/run-analysis/2026-10-22_gym-rustboro-design), one 90-minute phase from r10's Torchic RUSTBORO_CITY save (sha1 b4da158b).
- `pokebench_env.latest_main_loop` gains `FEATURE_RECIPE`: each trial passes `--feature-recipe <id>` so its arms come from `bundle-v-control-2h` on the trial's fresh main. Bundle changes on main reach the gym loop with no edit here. Unset keeps the previous argv exactly.
- The loop runs as its own detached controller with its own archive, lock, STOP and PAUSE files. A viewer STOP/ABORT on a gym run stops only the gym loop.
