# vLLM lane support for `just fixed-run`

Infra-only (no harness behavior change, no feature switch). Requested by the coordinator for the HyperQwen lane (vLLM at 127.0.0.1:18020, TP2, 2 seqs, vision).

## Scope

1. `fixed-cli.ts` `servingReceipt`: a vLLM receipt path (authenticated `GET /v1/models` + `/health` + `/version`); slots and vision come from the lane declaration.
2. `fixed-runner.ts`: per-lane key source (`apiKeyFile`, absolute path) read at launch into an owner-only endpoint file; the key is never in the definition, receipts, ledger, status or logs.
3. `local-endpoint.ts` `discoverLocal`: parse vLLM `/v1/models`; vision from the endpoint file's declared `vision`.

Lane fields (all optional, llama lanes unchanged): `server: "llama" | "vllm"`, `slots`, `vision` (vllm only, required there), `apiKeyFile` (absolute).
